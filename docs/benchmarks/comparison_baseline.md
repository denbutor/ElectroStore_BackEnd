## 2. Шаблон порівняння: Мікросервіси vs Моноліт

| Показник | Мікросервіси ElectroStore | Старий моноліт | Що порівнюємо |
| :--- | :---: | :---: | :--- |
| **RPS під навантаженням (`load` / `sustained`)** | `~125.5` / `~255.8 req/s` | *заповнимо* | Пропускна здатність |
| **Затримка `200 OK` (`med` / `p95`)** | `4.72–7.22 ms` / `11.39–95.43 ms` | *заповнимо* | Швидкодія під навантаженням і сплеском |
| **Частка помилок (`api_error_rate`)** | `0.00%` | *заповнимо* | Стабільність під навантаженням |
| **Реакція на збій одного модуля/залежності** | Ізоляція на рівні сервісів (`502` лише по впалому сервісу) | *заповнимо* | Відмовостійкість архітектури |
| **Споживання RAM / CPU** | Сума контейнерів (`catalog` ~`103 MiB`, решта `3.5–89 MiB`) | *заповнимо* | Накладні витрати інфраструктури |
