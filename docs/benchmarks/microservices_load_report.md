# Навантажувальне тестування мікросервісного бекенду ElectroStore (k6)

## 1. Умови експерименту
- **Інструмент:** Grafana k6 v2.4.0 (`loadtests/microservices_full.js`)
- **Точка входу:** `http://localhost:8000` (API Gateway / `nginx`)
- **Цільові сервіси:** `catalog` (`/api/v1/categories`, `/api/v1/products/`), `auth`, `order`, `ai`
- **Профілі:**
  - `smoke`: 2 VUs, 20s
  - `load`: плавний розгін до 10 -> 25 -> 0 VUs (80s)
  - `spike`: піковий сплеск до 60 VUs (65s)

## 2. Зведені результати (200 OK по каталогу та загальні метрики)

| Профіль | Макс. VUs | Усього запитів | Успішні `200 OK` | Усі запити `avg` / `p95` | `200 OK` `avg` | `200 OK` `med` | `200 OK` `p95` | `200 OK` `max` |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| `smoke` | 2 | 390 | 156 | 4.22 ms / 11.51 ms | 7.02 ms | 5.65 ms | 14.65 ms | 39.25 ms |
| `load` | 25 | 10 040 | 4 016 | 3.98 ms / 8.00 ms | 7.50 ms | 4.72 ms | 11.39 ms | 1089.50 ms |
| `spike` | 60 | 18 865 | 7 546 | 10.32 ms / 42.88 ms | 23.27 ms | 7.22 ms | 95.43 ms | 681.66 ms |

## 3. Ключові спостереження
- Медіанна затримка (`med`) залишається стабільно низькою (**4.72–7.22 ms**) у всіх трьох профілях, включно зі стрибком до 60 VUs.
- При піковому навантаженні (`spike`) `p95` для `200 OK` зростає до **95.43 ms**, а у профілі `load` зафіксовано поодинокий хвостовий пік `max = 1089.50 ms`.
- Помилок доступності або сервісної логіки (`api_error_rate`) не зафіксовано (`0.00%`).
